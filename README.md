# What-a-Wash! (WAW)

What-a-Wash! is a web application for a premium laundry and fabric care service. The platform features an interactive landing page to showcase services, pricing, and booking, as well as a comprehensive legal section.

## Project Structure

```
WAW/
├── index.html        # Main landing page
├── legal.html        # Terms of Service & Privacy Policy page
├── styles/           # CSS stylesheets
│   ├── style.css     # Main stylesheet for landing page
│   └── legal.css     # Stylesheet for legal page
├── public/           # Static media assets
│   └── shirt.svg     # Hero shirt vector graphic
├── favicon.ico       # Website favicon icon
└── README.md         # Project documentation
```

## Features

- Modern, responsive design optimized for desktop and mobile devices.
- Interactive hero section with animated background elements.
- Comprehensive services showcase covering wash, dry, fold, dry cleaning, and express pickup.
- Legal compliance documentation adhering to relevant privacy standards including the Data Privacy Act of 2012 (RA 10173).

## Getting Started

1. Clone or download the repository.
2. Open `index.html` in any modern web browser to view the application.

## Technologies Used

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- JavaScript (Vanilla JS)
